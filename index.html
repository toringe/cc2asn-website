The words, briefly

AS number

An autonomous system is a group of networks run under one routing policy, usually by an internet provider, a company or a university. Its number, the ASN, is a 16- or 32-bit integer, written plain (65551) or dotted (1.15).

Read more

Prefix

A block of IP addresses, also called an IP range or IP block, written as its first address, a slash and the number of fixed bits: 192.0.2.0/24 holds 256 addresses. Registries list IPv4 space as a start and a count, which CC2ASN turns into prefixes. IPv6 space is listed as a prefix already.

Read more

Country code

The two-letter ISO 3166-1 alpha-2 code the registry has on file for the holder, such as NO for Norway. Territories have codes of their own: SJ for Svalbard and Jan Mayen, PS for Palestine.

Read more
